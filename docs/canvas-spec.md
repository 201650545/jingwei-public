# 03 · 画布规范

> 最后更新：2026-10-19 22:10 ｜ 真源：`plugin/jingwei/client.js` 的 CSS 常量
> 一条总则：**画布上除了节点、连线、耗时，什么都不加。**

## 视觉

| 项 | 值 |
|---|---|
| 背景 | `#000` |
| 网格 | 点阵，`radial-gradient(rgba(255,255,255,.12) 1px)`，间距 24px，随平移/缩放同步 |
| 节点 | 背景 `#000`，1px 描边 `rgba(255,255,255,.26)`，圆角 3px |
| 节点 hover / 拖拽 | 描边提到 `rgba(255,255,255,.62)` / `#fff` |
| 连线 | 1px `rgba(255,255,255,.26)`，贝塞尔曲线，无箭头 |
| 文字 | 标题 `#fff` 13px/600；耗时 `rgba(255,255,255,.55)` 11px 等宽；模型名 `rgba(255,255,255,.34)` 10px 等宽 |
| 汇总节点 | 宽 156px，描边 `rgba(255,255,255,.18)`，更弱 |

**禁止**：任何色相（蓝/绿/黄/红/hsl）、渐变、阴影、圆角大于 4px、emoji、图标库。

## 尺寸与布局

| 项 | 值 |
|---|---|
| 分支节点宽 | 188px，内边距 12/13/11 |
| 分支间距 | 220px（世界坐标 x = i × 220） |
| 汇总节点 | 位于分支下方，y = 188，横向居中 |
| fit 内边距 | `min(48, max(16, min(w,h) × 0.06))` |
| fit 缩放上限 | 1.5（窄栏由宽度决定，通常 0.9 左右） |
| 缩放范围 | 0.25 ～ 3 |

窄栏（<1000px）不换布局，只按 fit 缩小；节点完整落在框内，本次实测 420px 下标题有效字号约 11.8px。

## 交互

| 操作 | 行为 |
|---|---|
| 拖节点 | 移动节点；连线跟随；不改变视图 |
| 拖空白 | 平移画布 |
| 滚轮 | 以光标为锚点缩放，0.25～3 |
| 双击空白 | fit |
| 双击节点 | **不触发** fit（节点上的双击被忽略） |
| `F` / `0` | fit |
| `R` | 重新读 `graph.json`，静默替换 |
| 窗口/面板尺寸变化 | 未手动平移缩放时自动 fit；否则只重绘连线 |

细节约定：

- 拖动阈值 2px，避免点击被误判成拖拽
- 热键只在画布有布局且未被隐藏时响应（`display:none` / `hidden` / `inert` 的保活实例不响应）
- `R` 请求带递增序号，旧响应不会覆盖新数据

## 新增 UI 的准入条件

先回答三个问题，缺一不批：

1. 这条信息在聊天/会话里是不是已经存在？（是 → 不加）
2. 它是不是只有点开一层才能看到？（是 → 说明它不常用 → 不加）
3. 它必须常驻画布才能完成当前任务吗？（否 → 不加）

## v0.2 交互（选中 / 菜单 / 预览 / 重跑）

| 操作 | 行为 |
|---|---|
| 单击节点 | 选中：border `#fff` + outline 1px `#fff`（视觉 2px）；不弹面板 |
| 单击空白 / Esc | 取消选中 |
| hover 节点 | 右上角出现 `⋯`（白 35%，hover 白 100%）；merge 节点没有 |
| 点 `⋯` | 黑底 1px 白边菜单，四项：重跑这一路 / 查看产物 / 复制模型名 / 删除节点 |
| 双击节点 | 查看产物（无产物无反应） |
| Enter | 重跑选中节点 |
| 菜单打开时 | Esc / 点外面 / 平移 / 缩放都关闭 |

**状态语言（仍只用灰阶）**

| 状态 | 画法 |
|---|---|
| idle | 1px 白 26%，耗时显示「—」 |
| selected | 2px 白 |
| running | 1px 虚线白 60% + 2.2s 呼吸；耗时显示「运行中」 |
| done | 1px 白 26%，显示 xx.xxs |
| failed | 显示「失败」，模型名降到 26% |

**产物预览**：全屏遮罩 `#000`，padding 40/48；顶部一行 11px 灰字「节点名 · Esc」+ ×。
json/text 用等宽 pre，html 用 sandbox iframe，图片居中 max 92%。点遮罩空白或 Esc 关闭。

**禁止**：菜单以外的常驻浮层、状态颜色、图标库、阴影、多选/框选。
